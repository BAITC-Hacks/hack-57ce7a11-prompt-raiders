# AI Sana Challenge Hub

Frontend-прототип платформы для задач бизнеса и решений студенческих команд. HTML, CSS и JavaScript без зависимостей.

## Запуск

Откройте `index.html` в браузере либо выполните `node server.js` и перейдите на http://localhost:3000. При установленном npm доступна команда `npm start`.

## Сценарий демонстрации на 5 минут

1. В конструкторе нажмите «Заполнить пример», затем «Анализировать ИИ». Появятся три вопроса и редактируемая карточка.
2. Ответьте, для кого решение, какой результат нужен, какие есть данные, сроки и способ связи. Нажмите «Обновить карточку и рейтинг».
3. Проверьте поля карточки и нажмите «Опубликовать». Задача появится в каталоге, отсортированном по убыванию рейтинга.
4. Откройте «Подробнее и откликнуться». Введите название команды, идею решения, план и ссылку HTTP(S) на прототип/GitHub.
5. Отправьте отклик. В кабинете команды он будет «На рассмотрении».
6. В разделе «Отклики бизнесу» вручную нажмите «Принять» или «Отклонить». Решение отразится в кабинете команды и сохранится после перезагрузки.

## Рейтинг готовности

Демо рассчитывает полноту полей по прозрачным правилам:

| Критерий | Баллы | Правило |
| --- | ---: | --- |
| Название | 10 | Минимум 5 символов |
| Контекст и проблема | 20 | Минимум 20 символов |
| Пользователь и потребность | 15 | Минимум 10 символов |
| Ожидаемый результат | 20 | Минимум 10 символов |
| Измеримый критерий успеха | 15 | В результате есть число или ключевые слова о метрике/проверке |
| Данные и ограничения | 10 | Минимум 10 символов |
| Срок и способ связи | 10 | В ограничениях указаны ключевые слова срока и контакта |

Статусы: 0–39 «Черновик», 40–69 «Рабочая», 70–89 «Готовая», 90–100 «Приоритетная». Это эвристика полноты, не экспертная оценка качества задачи.

## Файлы и интеграция

- `index.html` — конструктор, каталог, кабинет команды, отклики бизнеса и модальное окно задачи. Сохранены ID из исходного каркаса.
- `styles.css` — оформление, статусы и адаптивная вёрстка.
- `app.js` — навигация, `analyzeDraft`, `scoreCard`, публикация, отклики и localStorage.
- `server.js` — необязательный локальный сервер статических файлов.

Анализ — локальная демонстрация без ИИ. Для реальной интеграции замените `analyzeDraft` серверным запросом, а операции публикации/откликов — API с авторизацией. Ключи ИИ должны храниться на сервере.

Все роли доступны в одном браузере. Данные хранятся под ключом `ai-sana-hub-v1`; аккаунтов, разграничения доступа и синхронизации между устройствами нет. Старые данные предыдущей анкеты не затрагиваются. Шрифт загружается из Google Fonts; без сети используется системный.

Повторный анализ не перезаписывает ручные правки карточки. Кнопка обновления из трёх ответов заменяет соответствующие поля карточки. После публикации конструктор очищается для следующей задачи.

## Проверка

`node --check app.js` и `node --check server.js` проверяют синтаксис. В браузере проверен полный сценарий: анализ → уточнения → публикация → отклик → ручное принятие → сохранение после перезагрузки.
