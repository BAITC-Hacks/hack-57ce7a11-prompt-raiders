# AI Sana — главная и кабинет бизнеса

Откройте `index.html` в браузере. Главная сохранена, кнопка «Я представитель бизнеса» открывает кабинет.

## Экран 2

- «Создать задачу» открывает ввод названия и черновика.
- Сохранение возвращает в кабинет и добавляет задачу в список.
- У каждой задачи показаны статус (черновик, подтверждена, опубликована), рейтинг и число откликов.
- «Редактировать» открывает название и описание выбранной задачи. Изменение переводит задачу в черновики и сбрасывает устаревший рейтинг.
- «Посмотреть отклики» открывает предложения именно этой задачи или пустое состояние.
- Кнопка демо добавляет три явно отмеченные тестовые задачи всех статусов и два тестовых отклика. Повторной загрузки нет.

Рейтинг новых задач пока не рассчитывается; отображается «ещё не рассчитан». Демо-баллы фиксированы. Подтверждение, публикация, AI и отправка откликов не реализованы в этом изменении. Данные хранятся в localStorage (`ai-sana-business-dashboard-v1`), серверное API и аккаунты не подключены.

## Маршруты

- `#business` — кабинет бизнеса.
- `#draft` — создание черновика.
- `#edit/<id>` — редактирование задачи.
- `#responses/<id>` — предложения команд по задаче.
- `#catalog` — пока сообщение о неподключённом каталоге.

В браузере проверены переход с главной, создание и редактирование черновика, демо-статусы, количество и просмотр откликов. Основные файлы: `index.html`, `styles.css`, `app.js`. Backend-файлы не изменялись.

## Экран 3 — ввод и уточнение

`#draft` теперь содержит два состояния:

1. Описание (20–4000 символов), тема/отрасль, кнопка «Проанализировать». POST `/api/questions` отправляет `{ task: "Тема: …\nОписание…" }`. Во время запроса видна загрузка, повторная отправка блокируется. Тайм-аут — 45 секунд; уход с экрана отменяет запрос.
2. Минимум три вопроса с ответами, «Сформировать карточку» и «Вернуться к описанию». При неизменённом описании повторный переход сохраняет ответы. При изменении темы или текста вопросы запрашиваются заново.

Ошибки сети, HTTP, JSON и неверная структура вопросов показывают сообщение, возможность повтора и кнопку «Использовать стандартные вопросы». Ответ backend с mode=demo обозначается как стандартные вопросы; mode=fallback предлагает пользователю выбрать стандартные вопросы явно. Для mode=ai отображается AI.

Карточка собирается локально из исходного описания и точных пар вопрос/ответ, без выдуманных фактов, затем открывается редактор. Тема и ответы редактируются и сохраняются вместе с задачей. Публикация не выполняется автоматически. Промежуточное состояние хранится в `ai-sana-draft-wizard-v1`.

На статическом сервере без `/api/questions` работает предусмотренный сценарий ошибки и стандартных вопросов. Для настоящего AI нужен работающий backend с этим endpoint. Существующие backend-файлы не изменялись.

## Редактор карточки и рейтинг

Редактор `#edit/<id>` содержит десять отдельных полей. Ответы предыдущего шага сохранены в раскрываемой подсказке: произвольные AI-вопросы не преобразуются в поля по догадке.

Рейтинг автоматически пересчитывается при вводе. Веса: контекст и потребность 20 (по 10), материалы 20, результат 15, критерии 15, ограничения 10, пользователи 10, связь 10 (контакт и формат по 5). Незаполненные поля и явные значения «Пока неизвестно» не приносят баллов. Оценка полноты предварительная до ручного подтверждения; семантическая экспертиза содержания не проводится.

«Сохранить черновик» сохраняет поля. «Подтвердить карточку» сохраняет снимок текущей версии. После изменения полей публикация требует нового подтверждения. Проверяются название, формат контакта и обнаруженные ссылки HTTP(S). Остальные поля допускается оставить пустыми: публикация не ограничена минимальным рейтингом.

«Опубликовать» создаёт отдельный опубликованный снимок и открывает страницу `#task/<id>`, откуда есть переход в `#catalog`. Каталог показывает все опубликованные задачи и сортирует их по баллу. При редактировании черновика предыдущий опубликованный снимок остаётся доступен до новой публикации. Все операции локальные, в браузере; серверная публикация не подключена.

Проверены формула рейтинга и техническая валидация, повторное подтверждение после изменения поля и публикация карточки с рейтингом 20/100.
