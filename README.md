# AI Sana Challenge Hub

В проекте объединены три части командной работы:

- frontend: кабинет бизнеса, мастер создания задачи, каталог и предложения команд;
- AI: генерация уточняющих вопросов, формирование карточки и оценка готовности;
- данные: модели и JSON-хранилище задач, вопросов, команд, предложений и рейтингов.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm start
```

Откройте `http://localhost:3000`. Не открывайте `index.html` напрямую: API работает через `server.mjs`.

Без `OPENAI_API_KEY` приложение полностью демонстрируется на безопасных локальных генераторах. С ключом используются OpenAI Responses API и строгие JSON-схемы.

```powershell
$env:OPENAI_API_KEY="ваш-ключ"
npm start
```

## Сквозной сценарий

1. Выберите роль «Бизнес» и нажмите «Создать задачу».
2. Введите описание и отрасль. `POST /api/questions` вернёт 3–5 уточняющих вопросов.
3. Ответьте минимум на три вопроса. `POST /api/cards` сформирует редактируемую карточку.
4. Карточка, вопросы и рейтинг сохранятся в каталоге `data/`.
5. Подтвердите и опубликуйте карточку — она появится в общем каталоге.
6. Команда отправляет предложение; бизнес принимает, отклоняет или возвращает его на рассмотрение.

## Данные и API

JSON-файлы создаются при первой записи:

- `data/tasks.json`;
- `data/clarifying-questions.json`;
- `data/teams.json`;
- `data/proposals.json`;
- `data/ratings.json`.

Основные маршруты: `/api/questions`, `/api/cards`, `/api/tasks`, `/api/ratings/evaluate`, `/api/teams`, `/api/proposals`.
