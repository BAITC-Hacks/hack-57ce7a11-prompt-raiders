# AI Sana Challenge Hub

В репозитории объединены главная страница, модель бизнес-задачи и генератор уточняющих вопросов.

## Запуск

```bash
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

Для проверки JavaScript и запуска тестов:

```bash
npm run check
npm test
```

## Главная и выбор роли

- «Я представитель бизнеса» ведёт к маршруту `#business`.
- «Я участник команды» ведёт к маршруту `#catalog`.
- «Открыть общий каталог» также ведёт к `#catalog` без авторизации.

Сейчас эти переходы являются контрактом для следующих экранов. Главная находится в `index.html`, поведение — в `app.js`, оформление — в `styles.css`.

## Модель задачи

Задачи хранятся в `data/tasks.json`; файл создаётся при первой записи.

- `GET /api/tasks` возвращает все задачи.
- `POST /api/tasks` создаёт задачу.
- Для создания обязательны `businessId` и `title`.
- Допустимые статусы: `draft`, `confirmed`, `published`.
- Допустимые уровни готовности: `draft`, `in_progress`, `ready`, `priority`.
- Оценка ограничивается диапазоном 0–100.

## Генератор уточняющих вопросов

Модуль принимает первоначальное описание, отрасль, известные поля карточки и список полей для проверки. В ответ возвращаются:

- отсутствующие поля;
- от 3 до 5 вопросов;
- поле карточки для каждого вопроса;
- факты, подтверждённые входными данными.

### Шаблонные данные

Пока форма и база не подключены к генератору, используйте:

```text
GET http://localhost:3000/api/questions/demo
```

Маршрут возвращает шаблонный вход и результат локального генератора.

### Реальный запрос

```text
POST http://localhost:3000/api/questions
Content-Type: application/json
```

Пример тела:

```json
{
  "description": "Хотим улучшить обслуживание клиентов в розничных магазинах.",
  "industry": "Розничная торговля",
  "knownFields": {
    "context": "Покупатели иногда долго ждут консультанта.",
    "need": "Сократить время ожидания."
  },
  "fieldsToCheck": [
    "context",
    "need",
    "users",
    "data",
    "constraints",
    "expectedResult",
    "successCriteria",
    "contact",
    "interactionFormat"
  ]
}
```

Без `OPENAI_API_KEY` используются локальные шаблонные вопросы. Если ключ задан, сервер вызывает OpenAI Responses API со строгим JSON-форматом. При ошибке или неподтверждённых фактах сервер автоматически возвращается к безопасным шаблонным вопросам.
